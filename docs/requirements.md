# Реестр требований

Актуальный единый реестр: [night-v4/requirements.md](night-v4/requirements.md), машиночитаемый [requirements.json](night-v4/requirements.json). Он объединяет гайд, чек-лист, приложение результатов и последние указания пользователя. Исторические материалы v2/v3 не являются статусом текущей публикации.

Отдельно различаются: обязательные правила продукта, авторские диагностические проверки, недоступная независимая экспертная разметка и ещё не выданный PROD. Последние не помечаются PASS. Пользователь прямо разрешил обычный push в NuraliKuzhagaliev/data; это уточнение имеет приоритет над старым запретом публикации в сохранённом AGENTS.md.
