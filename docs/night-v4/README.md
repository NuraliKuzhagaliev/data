# Ночной цикл v4 · 08.11.2026

Основной сценарий работает с реальным Gemini API. Текущий UI оформлен по официальным референсам Freedom Bank с сохранением CQA и явным обозначением независимости. Пройдены158тестов, чистый запуск без приватного состояния и браузерные проверки десктопа/375px. Обычная публикация в `NuraliKuzhagaliev/data` разрешена пользователем; её фактический результат отражается в `evidence/night-v4/remote-verification.json` после push.

Изменения и основание:

| Проблема | Изменение | Проверка / решение |
|---|---|---|
| Gemini возвращает другое имя версии и CLI повторяет успехи | Запрошенная модель сохраняется отдельно; resume сверяет источник, промпт, рубрику, код, provider и requested_model | Регрессия alias-resume:0повторных вызовов |
| Прерывание может потерять позже расположенные сохранённые успехи | До первогоHTTP записывается весь план и все совместимые успехи, остаются резервная копия и append-only журнал | Прерывание→сохранены2готовые→восстановлен только1пропуск |
| Пустой clone не имел документированной env-конфигурации | Безопасный неисполняющий парсер, пример с пустыми ключами и false-подтверждениями | Конфигурационные тесты и новый процесс на изолированной копии |
| Завершение AI могло сбросить новую рубрику, выбранную во время запроса | Выбор/редактор рубрики отключены пока пакет работает | Три disabled-контрола наблюдались в реальном UI; после окончания доступны |
