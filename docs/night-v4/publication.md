# Публикация и данные

Пользователь прямо разрешил коммиты и обычный push в https://github.com/NuraliKuzhagaliev/data. Старый запрет публикации в AGENTS.md заменён этим уточнением только для данного репозитория; сам AGENTS.md сохранён байт-в-байт. Основание: `.bootstrap/authorization-2026-11-08.md`. История удалённого репозитория до работы была пустой, права push подтверждены. Force push, смена видимости, защиты, аккаунта или биллинга не применяются.

В Git включаются исходники, тесты, документация, собственные синтетические протоколы/попытки, снимки собственного UI и официальный DEV results.json. Последний не содержит сырого транскрипта: поляID, модельные ответы, краткие основания, номера реплик и баллы. Отдельно проверены основания5реальных звонков; публикация scores следует требованию приложения организаторов. Это не публичный набор персональных разговоров.

Исключены `.env`, `.local`, базы, ключи, входные организаторские данные, аудиозаписи и ссылки, подписанные URL, веса и бинарные runtime, кеши и банковская рекламная графика. Брендовый референс описан цветами и ссылками; логотип/шрифт банка не копируются. Публикация следует явному списку файлов; перед commit проверяются индекс и содержимое на реальные текущие ключи и токеноподобные строки. Это ограниченная проверка публикации, не сертификат безопасности.

Развёртывание не требуется: репозиторий содержит локальное приложение, которое запускается Python. После push проверяется удалённый SHA и CI Windows/Ubuntu, Python3.11/3.13. Сервер не опубликован в интернете. Для восстановления кода использовать обычный revert или отдельный checkout подтверждённого commit; перед заменой локальной базы сделать копию `.local/`. Миграции схемы в этом цикле отсутствуют. Настройки и исторические оценки сохранены.
