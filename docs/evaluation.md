# Методика проверки качества

Официальный человеческий Ground Truth и числовая формула соревнования не предоставлены. Поэтому точность относительно экспертов, per-criterion error и MAE итогового балла на организаторских данных UNKNOWN. Модельные предсказания не используются в качестве экспертных меток.

`tools/evaluate.py` поддерживает сопоставление по внешнемуID, шкалы, пропуски и отдельные ошибки: полный знаменатель сохраняется. Тесты проверяют пропущенные ответы, дубли, неизвестныеID, распределение семейств и source hashes. Подробности предыдущего аудита сохранены локально; новые регрессии находятся в `tests/test_quality_v3.py`, `test_audit_v2.py`, `test_night_v4.py`.

V3:40 собственных примеров,20 семейств минимальных пар. Семейства разделены между development и holdout; выбранные ответы заданы автором до inference. Протокол содержит происхождение меток и хеши. На20development-источниках той же Qwen сравнение v8→v9:22/25→25/25 целей,3исправления/0регрессий. Изменились подсказки и контракт, поэтому это сравнение всей цепочки, а не чистая абляция промпта. На20отложенных примерах Gemini:20/20валидных,21/21целей. Результат40/40 — инвентаризация обработки разными версиями/моделями, не единая accuracy лучшего ответа из нескольких.

V4: заранее зафиксированы6 новых случаев и12 выбранных ответов (контакт/грубые ошибки), в том числе изменение имени, перефразирование, оскорбление, prompt injection и107реплик. Реальный пакет запущен через браузер, метки не передавались модели. См. `evidence/night-v4/metamorphic-protocol.json` и `metamorphic-report.json`. Проверяется влияние изменения текста, не общая точность всех8критериев. Отдельное учебное изменение правила проверяет работу произвольной рубрики. Независимый повтор одного диалога даёт лишь локальную проверку стабильности, не статистическую оценку.

Источники, модель, запрошенная и фактическая версия, промпт, рубрика, параметры, токены, задержки и ошибки сохраняются. Оплата API в проведённых бесплатных опытах0USD по подтверждённому тарифу; расход электроэнергии, стоимость оборудования и фактический биллинг через API не измерены. Сбой не превращается в успех и не исключается из знаменателя. Контрактные mock-тесты вынесены отдельно от живых вызовов.

Предел вывода: авторские тесты подтверждают корректное выполнение выбранных правил на малом наборе. Они не доказывают совпадение с экспертами, надёжность на всей распределённой выборке, превосходство над конкурентами или победу.55историческихDEVаудитов имеют неполный coverage для critical=NO; это отдельный открытый долг, не скрытая правка старых оценок.

## Воспроизведение сводок без новых API-вызовов

В `evidence/quality-v3/runs/` опубликованы только собственные синтетические попытки, включая сбои, их manifests и снимки исходников трёх основных прогонов. Оригинальные организаторские транскрипты там отсутствуют. Для запуска существующих инструментов на чистом checkout:

```powershell
New-Item -ItemType Directory -Force .local/quality-v3
Copy-Item -Recurse evidence/quality-v3/runs .local/quality-v3/runs
python tools/quality_report.py --output .local/reproduced-benchmark.json
python tools/quality_compare.py
```

Сравнивайте содержимое сводки, не время генерации. Повторный inference может отличаться из-за версий сервиса и квот. Источники для нового запуска — frozen protocol, а не сохранённые ответы.
