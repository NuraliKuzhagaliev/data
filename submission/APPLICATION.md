## Краткое описание

CQA Evidence оценивает новые диалоги на русском, казахском и английском по восьми критериям Freedom Broker. Каждое решение связано с исходными репликами, а итог рассчитывается детерминированным кодом с учётом N/A. Проверяющий может изменить правило, подать апелляцию и сохранить собственное решение, не удаляя исходную оценку AI.

## Подтверждённые возможности

- Типизированные версии критериев, шкал, весов и условий N/A.
- Проверка исходных ID, ролей и покрытия транскрипта; цитаты извлекаются из оригинала.
- Карта влияния пересмотра на итог и независимый повтор без передачи первых ответов.
- Неизменяемая исходная оценка, отдельные апелляции и экспертные решения.
- Сохранённый план пакета, продолжение после ошибки и строгий официальный JSON.
- В облачном демо — код доступа, отдельные сеансы и закрытые серверные ключи.

## Архитектура

Python 3.11+, SQLite, HTML/CSS/JavaScript, облачные API Gemini и Groq на подтверждённых бесплатных тарифах. Основной запрос — `gemini-3.5-flash`; фактическая версия сохраняется из ответа API. Локальная Qwen3.5-9B была запущена на реальном GPU, но отклонена после провала длинного теста. Рабочим вторым режимом она не заявляется.

## Проверки и измерения

| Проверка | Результат и область вывода |
|---|---|
| Автоматические тесты | 171 тест; расчёты, контракты, HTTP, восстановление и границы облачного режима |
| CI | Windows и Ubuntu, Python 3.11 и 3.13 — четыре успешные проверки |
| Проверка размещённого демо | Два новых реальных вызова Gemini/Groq; 2/2 допустимых результата, 6/6 выбранных авторских ответов |
| Собственные сценарии v3 | Все 40 примеров обработаны в зафиксированных прогонах разных версий |
| Отложенная авторская проверка | На 20 примерах совпал 21 из 21 выбранного целевого ответа |
| Новые изменения текста v4 | На 6 примерах совпали 12 из 12 выбранных целевых ответов |

Авторские сценарии не являются независимым экспертным Ground Truth. Эти числа не доказывают общую экспертную точность на PROD и не гарантируют победу. Ошибки API и непроверенные случаи сохраняются в отчётах.

## Результаты и ограничения

`results/dev/results.json` содержит 65 ok / 0 error, команда THE BOYS. Формат 1.0 и точный набор ID проверены. В 55 исторических аудитах `critical=NO` покрытие исходника неполное: основания требуют перепроверки, старые баллы не подменялись.

Официальный PROD FBroker получен и обработан 08.11.2026: **10 ok / 0 error**, 80 решений, 129 проверенных ссылок, фактическая модель `gemini-3.6-flash`. [Результаты](../results/prod/results.json) опубликованы в GitHub и повторно скачаны для проверки; от получения набора до подтверждённого push прошло 296,25 секунды. SWAP: 3 диалога сохранены приватно без оценки и в PROD не включены. [Сводка](../evidence/deployment/prod-submission.json). Независимый экспертный GT, официальная числовая метрика, финальная формула победы и абсолютный стоп-код не предоставлены.

На Render Free сервис засыпает после простоя и теряет данные сеанса при перезапуске. Результат необходимо скачать. Официальный контрольный прогон рекомендуется проводить локально, сохраняя план и выходные файлы на компьютере.
